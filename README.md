# Portafolio

Este repositorio contiene una plantilla básica para un portafolio web personal.

## Estructura

- `index.html` — página principal.
- `styles.css` — estilos responsivos y modernos.
- `script.js` — pequeños comportamientos interactivos.

## Cómo usar

1. Abrir `index.html` en el navegador.
2. Editar el contenido y los textos según tu perfil y experiencia.
3. Reemplazar el correo de contacto con tu información real.

## Desarrollo

Este proyecto ahora usa Astro. Instala dependencias y ejecuta el servidor local con pnpm:

```bash
pnpm install
pnpm run dev
```

Si no tienes pnpm instalado, puedes usar Corepack en Node 16+:

```bash
corepack enable
pnpm install
```

Luego abre la dirección que muestra Astro en tu navegador.

## Estructura Astro

- `src/pages/index.astro` — página principal.
- `src/components` — componentes reutilizables.
- `src/styles/global.css` — estilos globales y diseño.
